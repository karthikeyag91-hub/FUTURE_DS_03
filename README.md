# FUTURE_DS_03

## Marketing Funnel and Conversion Performance Analysis

### Objective
Analyze customer behavior through the marketing funnel and identify drop-off points.

### Tools Used
- Microsoft Excel
- GitHub

### Key Findings
- Overall Conversion Rate: 12%
- Largest Drop-off: Product Views → Add to Cart

### Recommendations
- Improve product pages
- Simplify checkout
- Use retargeting campaigns
- Offer discounts and free shipping
